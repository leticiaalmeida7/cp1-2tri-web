# Referências Visuais

O CineTrack utiliza referências visuais de diferentes produtos digitais para orientar a construção da interface. As referências foram escolhidas considerando principalmente organização de conteúdo, descoberta de filmes e séries e acompanhamento pessoal.

As referências não serão copiadas diretamente. Elas servem como base para decisões de estrutura, navegação e apresentação das informações, mantendo uma identidade visual própria para o CineTrack.

## 1. Netflix

**Imagem:** `docs/references/imagens/netflix.png`

**Referência:** Netflix  
**Site:** https://www.netflix.com/

### Elemento utilizado como referência

A Netflix foi utilizada como referência para a forma de apresentar e organizar conteúdos audiovisuais. A disposição de filmes e séries em diferentes seções facilita a descoberta de novos títulos e permite que o usuário navegue visualmente pelo catálogo.

### Onde será utilizado no CineTrack

Esse conceito será adaptado principalmente para:

- Página inicial;
- Página Explorar;
- Exibição dos filmes e séries em cards;
- Organização dos conteúdos em diferentes categorias.

### Por que essa referência é adequada

A Netflix é uma referência adequada porque trabalha diretamente com grandes catálogos de filmes e séries e utiliza uma organização visual que facilita a exploração de diferentes conteúdos.

O CineTrack utilizará essa ideia apenas como referência de organização, desenvolvendo uma estrutura própria para o projeto.

## 2. Sofa Time

**Imagem:** `docs/references/imagens/sofa-time.png`

**Referência:** Sofa Time  
**Site:** https://www.sofatime.app/

### Elemento utilizado como referência

O Sofa Time foi utilizado como referência para os recursos relacionados ao acompanhamento do que o usuário deseja assistir, está assistindo ou já terminou.

Também foi considerada a forma como a plataforma organiza informações relacionadas ao acompanhamento de séries e episódios.

### Onde será utilizado no CineTrack

Esse conceito será adaptado principalmente para:

- Página Minha Lista;
- Status dos títulos;
- Organização entre "Quero assistir", "Assistindo" e "Concluído";
- Acompanhamento de episódios de séries;
- Indicação do progresso de uma série.

### Por que essa referência é adequada

O Sofa Time apresenta funcionalidades próximas à proposta do CineTrack, principalmente na organização pessoal dos conteúdos e no acompanhamento do progresso.

Essa referência ajuda a definir como o usuário poderá controlar sua própria lista sem transformar o CineTrack em uma cópia da plataforma.

---

## 3. Letterboxd

**Imagem:** `docs/references/imagens/letterboxd.png`

**Referência:** Letterboxd  
**Site:** https://letterboxd.com/

### Elemento utilizado como referência

O Letterboxd foi utilizado como referência para a apresentação das informações individuais de um filme e para a organização pessoal dos títulos.

A referência principal está na importância dada à página de detalhes de cada obra e às ações que o usuário pode realizar a partir dessas informações.

### Onde será utilizado no CineTrack

Esse conceito será adaptado principalmente para:

- Página de detalhes de um filme ou série;
- Exibição de pôster, título, sinopse, avaliação e informações gerais;
- Ação para adicionar o título à lista pessoal;
- Organização dos títulos salvos pelo usuário.

### Por que essa referência é adequada

O Letterboxd possui uma proposta voltada à organização e ao registro pessoal de filmes, tornando-se uma referência adequada para definir como as informações de cada título serão apresentadas no CineTrack.

O projeto utilizará somente os conceitos relevantes para o MVP, sem reproduzir sua interface ou funcionalidades sociais.

---

## Síntese das referências

As três referências foram escolhidas para funções diferentes:

| Referência | Principal contribuição para o CineTrack |
|---|---|
| Netflix | Descoberta e organização visual do catálogo |
| Sofa Time | Acompanhamento e organização do que assistir |
| Letterboxd | Detalhes dos títulos e organização pessoal |

A combinação dessas referências permite construir uma aplicação que une **descoberta de conteúdo, organização pessoal e acompanhamento de filmes e séries**, mantendo uma identidade visual própria.
